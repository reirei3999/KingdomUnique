# KingdomUnique

「建国とユニーク能力」をテーマにした Minecraft 1.21.1 / Fabric Mod。世界で唯一の能力・遺物・呪物、装備の無限強化、国民と英雄、設計図による自動建築、王国間の外交・戦争を実装しています。

## ビルド

Java 21 が必要です。対象は Minecraft 1.21.1、Fabric Loader 0.16.0 以上、Fabric API 0.105.0 以上です。GUI・HUDを利用するクライアントにも導入してください。

```powershell
.\gradlew.bat build
```

Linux / macOS では以下を使用します（`gradlew` に実行権限がなくても実行できます）。

```sh
bash gradlew build
```

生成された `build/libs/kingdomunique-0.1.0.jar` を `mods` フォルダに配置してください（ファイル名のバージョンは `gradle.properties` の `mod_version` に対応します）。

## GitHub リリース

大きな変更をリリースする際は、`gradle.properties` の `mod_version` を PR で更新してください。リポジトリのオーナーがその PR を `main` にマージすると、GitHub Actions が `v<バージョン>` のリリースを自動で作成し、配布用 JAR と自動生成されたリリースノートを公開します。

バージョンが変わらない場合や、同じタグがすでにある場合は公開しません。失敗した場合は、Actions から元の実行を再実行できます。

## ワールドと初期村

- オーバーワールドのボーダーは中心 `(0,0)`・`5000x5000`。バニラ村の通常生成を抑制し、互いに800マス以上離れた10箇所へ村の生成を予約します。周囲のチャンクがロードされると生成されます。
- 初回参加者には別途、`4000x4000` の範囲でランダムな開始地点を探し、所有者付きの初期村・王国倉庫と国民を用意します。初期村の周辺チャンクはロードを維持します。
- 王国名・中心・人口・領地・英雄召喚回数などを永続保存。通常の領地半径は100マス、王城・役場の完成で中心を固定して200マスへ拡大します。

## 能力・遺物・呪物の選択

- **初回覚醒**: 未覚醒の参加者へ、世界で未取得の能力をランダムに1つ付与します。
- **追加の選択**: ダイヤモンドの初所持で能力2択、人口15人到達で遺物3択、ネザー初到達で呪物5択のGUIを開きます。候補は未取得のものから抽選され、残数が少ない場合は候補数も少なくなります。未取得がなければ通知します。
  - 遺物の自動判定には、王国人口が15未満のときに周辺256マスの生存村人の総数を参照するフォールバックもあります。
- **世界で唯一**: 確定時に `WorldUniqueData` でIDを排他取得。競合して他プレイヤーに取得された候補は確定できません。未選択分は保存され、再ログイン時などに再表示されます。1人が複数のIDを保持できます。
- **能力12種**:
  - 生産・内政: 神匠（強化抽選・範囲採掘）、奇術（位置交換・分身）、豊穣（作物成長・収穫増）、現場監督（リーチ・採掘・建築補助）
  - 戦闘・身体強化: 覇王（与ダメージ・ノックバック耐性）、疾風（移動・落下軽減）、不屈（無傷時間による再生）
  - 特殊: 空間跳躍、物質透過、影渡り、絶対支配（敵対Mobの味方化）、重力操作（拘束・投擲）
- **遺物9種**: 豊穣の聖杯、戦勝の軍旗、賢者の設計盤、黄金の天秤、守護の結界石、不死鳥の羽根、職人の神槌、殺戮の宝剣、繁栄の揺りかご。回復・兵士・建築・資源生産・人口増加などを補助します。
- **呪物9種**: 血塗られた狂戦士の仮面、暴食の指輪、硝子の大砲、孤高の王冠、混沌のサイコロ、重力の足枷、背徳の契約書、虚無のランタン、破壊衝動のツルハシ。強力な効果と制約を持ちます。

## 無限強化と固有武器

- 金床の左右に**同じアイテム・同じ強化段階**の装備を入れて合成すると、通常は段階が `+1` 上昇します。対象は道具、弓・クロスボウ、トライデント、メイス、防具です。
- 段階 `N` に対して倍率は `1.1^N`。属性・耐久などへ反映し、名前に `+N` を表示します。段階は `kingdomunique:enhance_level` に永続保存します。
- 神匠は結果の取り出し時に抽選し、15%で `+3`、25%で `+2`、それ以外は `+1`。プレビューは `+1` 固定です。
- 固有武器はエクスカリバー、ゲイボルグ、ムラマサ、アポロンの太陽弓、ミョルニル、クロノスの短剣の6種。獲得トリガーと専用効果を持ち、遺物・呪物に対応する殺戮の宝剣／破壊衝動のツルハシも登録されています。

## ユニーク防具

各種ワールドに1点のみ。村のチェストには入らず、下の条件を最初に達成したプレイヤーに贈られます。ネザライト相当で耐久が減らず、エンチャント可能です。無限強化には、金床の右側に同じ部位・同じ強化段階の通常ネザライト防具を入れます（神匠の抽選も有効）。

| 防具 | 入手条件 | 装備効果 |
| --- | --- | --- |
| ハデスの隠れ兜 | ウォーデンを倒す | スニークで3秒静止すると透明化し、周囲のMobに見失わせる。攻撃・被弾で解除（CT 30秒） |
| ミーミルの叡智の兜 | 有効な本棚15個のある同じ台でLv30エンチャントを10回 | 獲得経験値2倍。エンチャント台と金床の経験レベル消費−30%（四捨五入・最低1、必要レベルとラピスは変化なし） |
| 竜鱗の翼鎧 | オーバーワールドの建築限界から最下部の岩盤層まで一度に落下して生き残る（水への着地可） | 胴装備のままエリトラ滑空・ロケット加速。炎と爆発の被ダメージ−40% |
| ネメアの獅子皮 | 素手でラヴェジャーにとどめを刺す | 近接被ダメージ−35%。メインハンドが空のとき攻撃力+4 |
| ヨトゥンの巨人脚甲 | トライアルチャンバーの異なる不吉な宝庫を5個開ける | スニーク中の被ダメージ−40%、ノックバック無効 |
| ヘルメスのタラリア | 一晩にファントムを10体倒す | 空中でジャンプキーを押し直して二段ジャンプ（CT 3秒、滑空優先） |
| サラマンダーの靴 | ストライダーで溶岩の上を累計333ブロック移動する | 足元の溶岩源を一時的に固め、炎上を防ぐ（炎・溶岩そのもののダメージは残る） |

## 王国・国民

### 国民化と役職

- 自国領土内の未所属村人に**スニーク＋右クリック**すると国民化。エメラルド1個、なければパン2個を消費します。背徳の契約書があれば無料ですが、国民死亡時に王が呪いダメージを受けます。
- 国民化時のメインハンドで役職を決定します。

| 役職 | 手に持つもの |
| --- | --- |
| 農民 | 小麦・ニンジン、または他の条件に当てはまらないもの |
| 建築士 | オークの板材・石 |
| 鍛冶屋 | 鉄インゴット・ダイヤモンド |
| 兵士 | 強化対象の装備（上記の条件を優先） |

- 兵士へ割り当てた装備は手から渡され、強化段階も維持されます。通常右クリックで兵士の装備画面、それ以外の国民は役職・施設に連動した独自交易画面を開きます。未所属村人の通常右クリックはバニラ交易のままです。

### 人口上限・自然増加・穀物庫

- HUDと実体国民の自然増加で使う上限は**初期10人＋完成民家1棟につき5人、最大40人**。初期村の民家は加算対象外です。HUDの人口は、王城・役場（なければ王の位置）を中心とする周辺128マスの生存国民を数えます。
- `PopulationManager` はオーバーワールドで12000tick（10分）ごと、夜間のみ出生を判定。王が同じワールドにオンラインで、中心がロード済み、国民が2人以上かつ上限未満なら、パン4個を消費して成長進捗を加算します。
- 進捗は通常1回 `0.5`、**王立穀物庫**で1.3倍、**繁栄の揺りかご**でさらに1.5倍。進捗が1以上になると農民の国民を1人生成します。穀物庫は必須条件ではなく加速施設です。
- 食料は王城・役場／穀物庫／交易場の施設範囲内の収納から優先消費し、不足分を王のインベントリから補填。HUDには国庫のエメラルド・パン在庫を表示します。
- 現行コードには別途、`KingdomManager.tickGrowth()` による400tickごとの確率的な**人口データのみ**の加算も残っています。国民化や遺物の判定に使う保存人口と、HUDの実体人数は一致しない場合があります。
- 王がオンラインの間は20分ごとに維持費を徴収。国庫・王の所持品で支払えないと衰退処理が進みます。政策は富国強兵令・殖産興業令・国境警備令から選択し、変更には7日間の制限があります。

## 建築（設計図・建築現場・建築士）

1. 設計図ブロックを置くと、所有者と向きを持つ**建築現場**を登録します。設計図を持つと範囲・入口をプレビューできます。
2. **建材を持って設計図を右クリック**すると直接投入。必要資材が揃うと消費して建築待ちへ移行します（空手右クリックでも開始確認）。不足・不要資材は通知されます。投入済みで未消費の資材は設計図を壊すと返却されます。
3. 周辺128マスから自国の**建築士**を探して現場へ誘導し、現場周辺の建築士が作業します。人数に応じて進行が速くなります。所有者が同じワールドにいない、現場が未ロード、作業できる建築士がいない場合は進みません。
4. 完成時に整地・構造配置・完成施設登録を行います。高度・未ロード範囲・既存建物や現場との重複・破壊不能ブロックなどは開始前に検査します。クリエイティブでは検査後に即時完成します。

※ 表の「鉄」「金」はインゴットです。民家・兵舎・鍛冶工房・王城の4種はクラフトレシピがあり、国民交易にも施設条件付きの設計図報酬があります。

- **現場監督**: 実際の建築処理 `BuildingManager` では資材倍率を `-0.30`、時間倍率を `-0.30`（単独なら各0.7倍）にします。
- **建築補助**: 賢者の設計盤は時間倍率0.5、周辺のヘファイストスは資材倍率 `-0.20`・時間倍率 `-0.30`。政策も時間倍率へ反映します。資材倍率の下限は0.4、時間倍率の下限は0.15です。
- **施設効果**: 穀物庫の成長補助、救護院の再生効果、交易場の定期収益、軍事庫の耐性、訓練場の攻撃強化、王宮の王への効果などがあります。監視塔は侵入警告、門は王・国民・英雄・同盟相手への自動開閉に対応します。
- 王城・役場／祭壇／王宮は各1王国1つまで。王宮には王城・役場の完成と人口データ30人以上が必要です。

## 英雄

- **角笛**、または完成した**英雄召喚の祭壇のロードストーンを右クリック**して召喚します。通常1王国1回、戦勝の軍旗があると2回まで。召喚時は雷と全体公告で通知します。
- クラスは刺客／騎士／弓手／鍛冶師の4種からランダム。所有者の右クリックで随伴／防衛／待機を切り替えます（孤高の王冠では随伴不可）。
- **Gキー／憑依のオーブ**で近くの自分の刺客英雄へ憑依し、視点と移動操作を切り替えます。もう一度で解除。スニーク＋ジャンプの大ジャンプ、刺客の落下ダメージ無効にも対応します。

## HUD・GUI・操作

- **統合HUD**: 覚醒能力・採掘範囲・保有ユニーク数・人口／上限・国庫在庫、能力アイコンとクールタイム、状況に応じた設計図の必要／投入資材を表示します。F1でHUDを隠すと非表示になります。
- **GUI**: 能力等の選択、詳細ステータス、王国名入力、国民交易、兵士装備、管理者アイテムメニューを実装。建築範囲は3D線枠・パーティクルでも表示します。
- **JEI連携**: JEI導入時は建築資材・基本時間と、国民交易・施設条件を専用カテゴリで確認できます。

| 初期キー | 操作 |
| --- | --- |
| R | 能動能力の発動 |
| V | 神匠の採掘範囲切替（1x1 / 3x3） |
| G | 刺客英雄への憑依／解除 |
| I | 管理者アイテムメニュー（OP権限レベル2以上） |
| K | 詳細ステータス画面 |
| H | 兵士命令の一斉／個別切替 |
| J | 視線先への兵士移動命令（個別モードでは見ている兵士を選択） |
| スニーク＋J | 兵士のスタンス切替（個別モードで兵士を見ている場合は選択を優先） |

一斉命令の対象は周辺32マス。キーはMinecraftの操作設定から変更できます。

## 外交・戦争・防衛

- 同盟／中立／戦争の外交状態に基づく兵士・英雄の索敵と戦闘、国民の名札表示に対応します。
- 同盟相手以外のプレイヤーを撃破すると王権略奪の対象となり、敗者が持つ遺物・呪物・固有武器のIDからランダムに1つを移転します（能力IDは対象外）。宣戦布告は必須条件ではありません。
- 7日周期の夜に王国へ大襲撃が発生し、朝に襲撃者が残っていなければ防衛褒賞を得られます。
